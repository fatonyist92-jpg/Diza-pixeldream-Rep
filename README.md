# Diza PixelDream Rep

A personal black-and-white creative AI studio inspired by the workflow of PixelDream.

## Current phase
UI/UX foundation only. Provider and GPU integration are intentionally deferred.

## Design lock
- Pure black background
- White primary typography and controls
- Subtle neutral-gray surfaces and borders
- Mobile-first responsive layout
- Minimal, professional creative-studio feel

Reference project: chartmann1590/pixeldream (reference only; this repository is an independent implementation).
